JAVA PROGRAMS ON WORDS

1. Print each word line by line
2. Print first character of each word
3. Print last character of each word
4. Print each word length
5. Print each word whose length is even
6. Print each word whose length is odd
7. Print each word whose length is 3
8. Print count of words
9. Convert first character of each word to lowercase
10. Reverse each word in its place
11. Find the longest word
12. Find the smallest word
13. Capitalize first character of each word
14. Sort characters in ascending order
15. Sort characters in descending order
16. Anagram
17. Pangram

Each program is a separate Java file and can be compiled/run independently.
